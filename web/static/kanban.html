        Auto-Dispatch
        
    
        While it is on, tasks of this project start with no one pressing Run, a text an agent wrote too.
        
    
    
        
    
    
        How tasks are picked
        
    
        
      
      
    
        
    
        It takes tasks of severity
        
    
    
    
        
    
        
      
        What it takes
        TODO tasks of the severities ticked that nobody runs, made, moved or edited no later than the wait ago: one still being written is left; a comment does not start the wait anew. A task it started once it starts again only after you move or edit it. A task with subtasks still to do waits for them.
        
      
        In what order
        Down the board, exactly: P0 first, then the cards' order, each task while its agent has a free slot; drag a card up to have it start sooner. No agent reads the tasks: one whose text does not say what to do starts all the same. A task runs on the agent named in its window, else on the default one.
        Down the board: P0 first, then the cards' order. A round, one more session of the picking agent that takes no slot, is given the first few tasks for each free slot; it reads them, scores them by RICE (reach, impact, confidence, effort) and starts the best; one round at a time over all projects, the project that waited longest first. What it leaves with a slot still free is passed over for a day, unless you move or edit it, and the next round gets the tasks below; after a round that started nothing it rests half an hour, unless a task is made or changed. A task runs on the agent named in its window, else on the default one.
        
      
        When it waits
        No free slot, or no task to take; the tasks of its 24 hours are started; an agent past its week's or month's limit starts nothing.
        
      
        When it stops
        You turn it off: what runs goes on, nothing more starts. It turns itself off, saying why here and in the bar, when its round fails, a task cannot be started, or two tasks it started fail in a row.
        
    
        
    
        
    
        
      
      
    
        
  
        
        


  
        
    
        Memory limits
        
    
        terminum adds up the memory of the agent's processes every 30 s. Two readings in a row over Warn tell the agent; over End its tasks fail and it is ended. Nothing stops a process between readings: this is a watch, not a limit the system holds.
