As after ssh in a terminal: a Host of ~/.ssh/config, or user@host with -p -l -i -J. Your keys sign in; ssh must not ask for a password.

Its files and its coding agents' progress are set up on the host by themselves (a small helper in ~/.terminum, terminum's hooks in ~/.claude and ~/.codex).

        Severities it takes
        
      
        
        
        
      
        
      
      
        
        
        What it takes
        TODO tasks of the severities ticked that nobody runs, made, moved or edited no later than the wait ago: one still being written is left; a comment does not start the wait anew. A task it started once it starts again only after you move or edit it. A task with subtasks still to do waits for them.
        
        
        In what order
        P0 first, then saved task order, each task while its agent has a free slot. The columns' display sort does not change which task starts. No agent reads the tasks: one whose text does not say what to do starts all the same. A task runs on the agent named in its window, else on the default one.
        P0 first, then saved task order, independent of the columns' display sort. A round, one more session of the picking agent that takes no slot, is given the first few tasks for each free slot; it reads them, scores them by RICE (reach, impact, confidence, effort) and starts the best; one round at a time over all projects, the project that waited longest first. What it leaves with a slot still free is passed over for a day, unless you move or edit it, and the next round gets the tasks below; after a round that started nothing it rests half an hour, unless a task is made or changed. A task runs on the agent named in its window, else on the default one.
        
        
        When it waits
        No free slot, or no task to take; the tasks of its 24 hours are started; an agent past its week's or month's limit starts nothing.
        
        
        When it stops
        You turn it off: what runs goes on, nothing more starts. It turns itself off, saying why here and in the bar, when its round fails, a task cannot be started, or two tasks it started fail in a row.
        
      
        
      
        
    
        
    
        
      
        Finished tasks queue their commits; terminum merges up to the batch's size that merge cleanly, runs Check once on the candidate, and publishes only a candidate whose check was green. A red one goes to the agent below.
