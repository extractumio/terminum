# v0.11.0 — A phone's button row, Attach, and an honest unread mark

## Added

- **A menu on the terminal's input**: on a phone, hold a finger still on the input for 2.5 s
  for Paste (left out when the clipboard is known to be empty), Undo and Redo. The keyboard
  button's hold opens the same menu. Pasting an empty clipboard says so and sends nothing.
- **Attach** on a phone: pick several files; their paths are typed at the cursor, no Enter.

## Changed

- **A phone's buttons**: Attach, bookmarks, reminders and the split stand in a row at the
  bottom left, under the input; find and the sent history stay at the top right. A button's
  pane opens above it.
- **The agent's input box** on a phone is a tint, with no frame.
- **The reminders' bell** sits on the same fill as the other buttons; the bell itself is pink.
- **The session list**:
  - every row's folder bar stands at one place;
  - the bookmarks' and reminders' wavy lines are thinner and gentler;
  - a group's count says what it counts ("3 sessions"), and the counts line up;
  - a terminal's icon is white on a dark gray tile;
  - a working agent's bar pulses (no hourglass);
  - the shown session's row takes its project's tint rather than a box of its own;
  - a project's name has no mark before it.
- **The unread mark** is smaller and in the session name's color, on Clone's place: Clone
  covers it when it shows.

## Fixed

- **A session came up unread while its agent still worked.** Without terminum's hooks,
  - Claude Code's "Waiting for N background agents to finish" now counts as working;
  - so does a shell, a monitor or an agent still running in the background (Claude Code's
    footer counts it: "1 shell, 1 monitor"), though the main agent has finished;
  - a turn read from the screen ends only once the pane has stayed done for 10 s;
  - a busy row never shows the unread mark.

  Reminders follow the same rule. With hooks installed, a turn ends at its Stop, or, when a
  shell or an agent it started still runs in the background, once that ends.
- Files and View on a phone take the whole space under the tabs again (since the split view
  they had half the height).
