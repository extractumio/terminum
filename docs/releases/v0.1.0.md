# v0.1.0 — terminum, the first release

terminum is the successor of iterm-enhancer, feature for feature, without iTerm2: terminals
live in a private tmux server, and a browser on the Mac or a phone reads them.

## What it is

- **terminumd**, one Rust server on `127.0.0.1:47900`, run as the launchd agent
  `io.terminum.terminumd`: the tmux control client of a private tmux server (`tmux -L
  terminum`) and of each remote host over ssh. tmux emulates the terminal; the page gets
  only the rows that changed.
- **The session list**: tmux sessions, windows and panes, coding agents' states (working,
  waiting for an answer, failed), a reminder when an agent in another pane waits, a copy
  button with the command that attaches another terminal to a session.
- **The terminal** in **Wrap**, **Grid** or **Fit**, and **Screen mode** for full-screen
  programs. Also widgets for code, Markdown, diagrams and images in the output, folds,
  bookmarks, search, hot keys for phones, and paste and upload of files.
- **The Files panel**: the tree of the shown pane's folder, a viewer and editor with
  highlighting and rendered Markdown, create, rename, Trash and live refresh.
- **Remote hosts** (`terminum hosts add`, or **Add host** under the list): terminumd holds
  the host's tmux session `terminum` over ssh and reconnects after a drop. It browses the
  host's files through a helper, which it copies only after you enable it.
- **Sessions outlive everything**: terminals live in tmux. terminumd comes back after a
  crash. After a reboot the sessions, windows, splits and folders are restored.
- **A phone or another computer**: `terminum web on` with a password (off by default).

## Installing

```bash
curl -fsSL https://github.com/extractumio/terminum/releases/latest/download/install.sh | sh
```

Needs macOS 14+ and tmux 3.2+ (`brew install tmux`). Coming from iterm-enhancer, run
`terminum import`: it takes the workspaces, bookmarks and hosts.

## Validation

The following pass on the released tree:

- Rust unit tests and `cargo clippy` with no warnings; UI, page and script unit tests
  (`make test`).
- The protocol checks against a private terminumd and tmux server: core, access, restore,
  sizing, and remote hosts through a stand-in ssh.
- The page's browser checks in Chromium and WebKit, at a wide and a phone size. The Files
  panel's browser checks, and the live checks against a private tmux server.
- `scripts/security_check.sh`, and the installer's check in a temporary home.

Not checked: a real sshd for remote hosts (a stand-in ssh plays the host). This is the
first release, so there is no upgrade from an earlier release to check.
