# v0.21.0 — drop files into Files; a calmer list; settings alone in ⋯

A minor release: a new feature (uploading by dropping files on the Files tree) and a moved menu.
Nothing to set up; the install and upgrade are as before.

## New

- **Drop files from Finder onto the Files tree.** They upload into the folder under the pointer
  (a file's row: its folder; below the rows: the root), on this Mac or the pane's host. While
  you drag, that folder is marked and a line says where they go; move up or down to pick
  another. A name already there asks Keep Both or Skip: nothing is ever written over. Up to
  100 MB a file; a folder dropped is not uploaded (the toast says so).
- **Paper**, a light color scheme with soft pastel hues, among the menu's colors (in Cobalt2's
  place).

## Changed

- **The header's ⋯ holds settings only** (and Sign out). Split Below, Right and Left, Move to
  Session… and Close Session are in a session row's menu (a right click, or a finger resting on
  the row).
- **A selection's Copy, [+] and Ask** stand in the floating buttons' column, starting level with
  the selection's first line; the column's other buttons step aside while they show. The
  floating buttons lift and nod under the pointer.
- **The buttons under the session list** (New session, Bookmarks / Reminders, Add host, Attach
  tmux sessions) fold into one slim row of icons on a computer and unfold while the pointer is
  over them.
- **Every group in the list is tinted**, each in a hue apart from its neighbor's, so the groups
  under the projects no longer run together.
- **A row shows where its coding agent works** (a worktree it moved to), as the header does,
  with "Follow the agent's folder" on.
