# v0.9.0 — Projects, Clone, unread, and an IDE's keys

## New

- **Projects.** A row's menu (right click, or a finger resting on it) has Add to Project…:
  named groups of sessions ("Group 1", renamed from the project's ⋯), each in a color of its
  own far from the others, on its tint, its name and its rows' bars. Projects come first in the
  list; [+] opens a window in the project's folder; drag a project, or a session in it, to
  reorder. They are kept by terminumd (`projects.json`), the same on every browser, and keep
  their sessions across a restore after a reboot.
- **Clone** on every row: a new window right after it, in its folder. It replaces the groups'
  [+]. The row's menu also has Remove from Project, Close Session, Move to the Top, Up, Down and
  to the Bottom, and × to close it; the pane menu's "Close pane" is "Close session" too.
- **Unread.** A session whose agent finished a turn while no page in sight showed it gets a
  small blob in its group's color, beside Clone, until you open it, on every page.
- **An IDE's keys**: ⌘[ and ⌘] go back and forward through the last 20 sessions you showed, ⌘F
  opens the history's search, ⌘B opens or closes Files. ⌘Z sends the program's undo (Claude
  Code, zsh, bash, fish); ⌘⇧Z redoes where the program can (fish), and says so where it cannot.
  On a phone a finger resting on the keyboard button offers Undo and Redo.
- **⌘V after a copy from the history** pastes into the terminal's input at once, no click first.
- **Tool output folds on the screen too**, by the history's rules, before it scrolls up.
- **One color scheme for every browser**, kept in `settings.json` (`page.colorScheme`). A
  scheme an older page kept in its own browser is not carried over: pick it once more.

## Changed

- A row's second line shows the folder first and the program at its right edge.
- A pane's grid stays between 45×14 (an iPhone in portrait) and 240×70 (a large desktop
  window): a smaller view draws it scaled down, a larger one leaves the rest blank.
- A tmux reached twice (two hosts that are one machine, a host that is this Mac, grouped
  sessions, a linked window) lists each pane once, and a session listed already cannot be
  attached again. terminumd tags each tmux server it reaches with a server option,
  `@terminum-id`.
- The search's magnifier is out of sight while its field is open; a reminder's quote has a
  wavy pink line instead of the card's edge.

## Fixed

- A paste on a host that started with "-" failed with "parse error: command set-buffer: invalid
  flag -"; so did naming a window "-x …" and a path the Files panel typed that starts with "-".
- A Claude Code session showed done while subagents it started still ran in the background. It
  now stays working, with their number, until the last one stops, and its reminders and unread
  mark come then.
- Closing the last window of a host whose tmux had no other session brought the window back
  ("Restored host …: 0 sessions, 1 window"). The last pane closed by you is no longer restored,
  on a host, in terminum's tmux or in your own.
- The sizing check for a dragged window failed now and then: the test, not terminumd, assumed
  the once-a-second limit started at its first size.

## Known

- tmux ends the same way when its last pane closes and when it is stopped cleanly (kill-server,
  a host shut down): a server stopped so while it showed one pane is not restored (its shell
  comes back in `~`).
- The new keys do not reach a split's quick shell.
