# v0.22.0 — a Linux server; rename a session group; many fixes

A minor release: new features (terminum as a server on Ubuntu or Debian, renaming a tmux
session's group) and a changed install for Linux. On a Mac the install and upgrade are as before.

## New

- **terminum runs as a server on Ubuntu and Debian.** The same package installs a systemd user
  service there; its terminals live in tmux and outlive restarts and upgrades, as on a Mac. Other
  devices reach it through `tailscale serve`.
- **Rename a session group.** A tmux session's group in the list has Rename… in its menu (a
  right click on its header, or its ⋯): it renames the tmux session, and the group keeps its
  place and whether it is folded. A project's Rename… is in its own menu, as before.
- **The page ships JetBrains Mono Nerd Font** for devices without it.
- **macOS asks for the protected folders once, at install**, so no prompt waits on the Mac's
  screen while you work from the phone; `terminum folders` asks again.

## Fixed

- **Ask's Send to Agent** presses Enter only in the pane the quote went to, while its coding
  agent still runs: switching panes within the moment before it, or the agent ending, no longer
  runs a line in another terminal or a shell (a toast says the Enter was not pressed). Send to
  Agent hides when the agent ends while the dialog is open; after a timeout the buttons work again.
- **Unread marks** set just before a restart or an upgrade are kept.
- **History pages** at tmux's history limit are numbered right when tmux trimmed and refilled
  its history to the same count.
- **A collapsed group's menu** keeps New Session and Close Group.
- **The sent history's and the reminders' panes** keep Tab and the keys inside them.
- **On an iPhone** a selection no longer breaks when the terminal updates while the page puts
  iOS's menu away; the space bar's trackpad moves one character over an emoji.
- **Files:** a JSON or YAML file of 100,000 values opens quickly (a page of rows at a time); a
  YAML key twice, a key named `__proto__` and an escape past Unicode are handled (an error with
  its line, or a member like any other); a CSV's last empty record and a column first met after
  row 5000 show; a video or sound stops when its tab closes; a picture's address works while it
  is shown; MIDI renders two at a time and stop when their tab closes.
- **Keep Both** works when the name is taken by a link to a file outside the writable folders;
  a new file or folder on such a name says it exists.
- **Uploads and pastes** are read only once one of the two upload slots is free, on a Mac and on
  a host's agent.
- **A Linux install of a release** names the release's build (it refused: the build cached for
  its agent was another).
