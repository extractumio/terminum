# v0.20.0 — Sounds, PDFs and data in View; the agent's folder; a security fix

A minor release: new features (View shows PDFs, plays videos, every sound and MIDI, renders
JSON, YAML, CSV and TSV; Files follows the coding agent's folder; drag from Files; Mark as
Unread) and a new endpoint (`POST /api/midi`), so the next minor after v0.19.1. It also
carries a security fix: update.

## Security

- **A picture or a video can no longer run script in terminum's page.** Since v0.19.0 files
  were shown from `blob:` addresses, which belong to the page; an SVG or an HTML file opened
  with Open Image in New Tab (or a video's Open in New Tab) ran its scripts there in Chrome,
  with the sign-in in reach. Now only pictures, videos, sounds and PDFs keep their type; an SVG
  is shown from a `data:` address of its own, anything else downloads.
- **A remote host's file is typed by terminumd**, by its name and with the sandbox policy, never
  by what the host says; every other answer from a host is JSON.

## New

- **View plays and shows more**: PDFs in the browser's own viewer; videos and sounds in its
  player; AU and AIFF decoded where the browser does not play them; **MIDI** rendered on the
  Mac with your General MIDI SoundFont (put a `.sf2` at `~/.terminum/soundfont.sf2` or name one
  in `settings.json` as `midi.soundfont`; none is shipped), played in the same player, so it
  seeks and pauses as any sound.
- **JSON, YAML, CSV and TSV open rendered**: a tree in the editor's colors, open as far as is
  reasonable, that folds and copies values; a table with a sticky head. Source shows the text.
- **The coding agent's folder**: when Claude Code works in a worktree below where it started,
  the header and Files show that folder, and paths it prints (`artifacts/…/shot.png`) are
  links again. Settings' "Follow the agent's folder" turns it off (`page.followAgent`).
- **Drag files and folders from Files onto the terminal**: their paths go to the input, quoted,
  without Enter.
- **Mark as Unread** in a session's menu (Mark as Read on an unread one).
- **Esc in View** hides it and goes back to the terminal.

## Fixed

- `custom.css` applies from the first moment the page shows, not after it connects.
- A video in an HTML document no longer holds its memory after its tab closes.
