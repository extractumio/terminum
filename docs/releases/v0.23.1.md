# v0.23.1 — long quotes reach Claude Code whole on ssh hosts

A patch release: one fix since v0.23.0, nothing new to set up.

## Fixed

- **A long quote from Ask reaches Claude Code whole on a Linux host.** Claude Code on an ssh
  host showed a long quote folded ("[Pasted text #13 +13 lines]"), with the blank line after
  it inside the fold, so several quotes ran together on one line. Claude Code takes more
  than 800 characters read at once for a paste, and a Linux terminal hands a program up to
  4 KB at once (a Mac's 1 KB parts stayed under it). terminum now types more than 512 bytes
  in parts, each once the program read the last. A 3 KB quote takes a fraction of a second
  longer to appear. A quote taller than half the pane is still pasted and folded, as before:
  an agent's box taller than the pane breaks its redraw.

## Verified

`make test` (cargo 646 + 1, the Panel's and the Page's unit tests), the Panel's browser
check (157), the Page's 1449 browser checks (Chromium and WebKit, a wide and a phone size),
the live check against a private tmux 3.6a (181: a 2.5 KB quote typed by the page reaches a
slow reader in reads of at most 441 bytes; 1022 with v0.23.0) and `scripts/security_check.sh`
pass; clippy clean. Claude Code 2.1.312 in a private tmux folds what it reads at once over
800 characters (785 typed, 805 folded) and shows a quote typed in parts whole. Not verified:
Ask on a real Linux host.
