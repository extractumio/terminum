# v0.19.1 — No "[D" in an agent's input; Ask's quote as a Markdown quote

A patch release: fixes and small changes to existing UI since v0.19.0, no new feature, no
change to the protocol, install or upgrade.

## Fixed

- **No more "[D" or "[C" in a coding agent's input.** Moving by lines in a long message (held
  arrows) sent one burst of more than 1 KB, which the terminal hands on in pieces; a piece
  could end inside an arrow's bytes, and the agent took the rest for text. Long runs of keys
  now go in parts of 100, each after the pane answered the last (at most 250 ms).

## Changed

- **Ask's quote reads as a quote**: `> Quote #0007`, then each line of the selection after
  `> `, a blank line, your comment or question and another blank line, so quotes no longer run
  together. In a coding agent's input it is typed, so the agent shows it whole instead of
  folding it into "[Pasted text]"; a quote that would fill more than half the pane is still
  pasted (and folded), which keeps the agent's screen from breaking. In a shell it is pasted.
- **Ask's field has no "Question" label** (it holds a comment or a task as often) and says
  "Your comment or task about it".
- **A field in focus has no accent gradient**: an accent edge over its usual fill, on every
  field.

## Under the hood

- A debug build checks a password about three times faster (the same hash); the live checks'
  sign-in no longer times out on a busy Mac.
