# v0.13.0 — The text keeps its size when the view changes width

## Fixed

- **The terminal's text jumped when the view changed width.** Opening docked Files, narrowing
  the window, turning a phone or pressing − and + first shrank the text to fit the pane's old
  width, then grew it back a moment later, when tmux had re-wrapped the pane at the new width.
  Now the text stays at the chosen size: the rows are cut off at the view's edge for that
  moment (no sideways scrolling), and the pane is then drawn re-wrapped once.
  A pane that does not take the new width within 2 s (a window of several panes, one sized
  for another screen, a refused resize, the 45-column floor) is drawn scaled to the view, as
  before.
