# v0.26.1 — selecting in a full-screen program shows Copy, [+] and Ask

A patch release: selecting text in a full-screen program that has the mouse (Claude Code's
fullscreen mode) showed no buttons, and Shift selected nothing in Chrome and Firefox. Nothing new
to install; `terminum upgrade` brings it.

## Fixed

- **A selection in a full-screen program shows Copy, [+] and Ask.** A program that has the mouse
  gets the drag, so the browser selected nothing and the buttons never came. When the program
  copies what it selected (Claude Code does, with OSC 52), terminumd now reads that copy from the
  pane's output and the page shows Copy, [+] and Ask with its text by the selection's upper row;
  they stay while the program redraws and go with the next click or key.
- **Only a copy you asked for.** terminumd takes a program's copy only within 2 seconds of this
  page's mouse release over that pane, the page shows it only when its text is on the screen, its
  control characters are removed (a Copy pasted into a shell cannot end the paste or send keys),
  and nothing reaches the clipboard or an agent until you press a button.
- **Shift and a drag select in every browser.** In Chrome and Firefox Shift extended the
  keyboard field's caret and selected nothing; the page now selects from where you pressed, and
  nothing goes to the program.

Programs that do not copy their own selection (vim, mc) get the drag as before: Shift and a drag
select in the browser and show the buttons.
