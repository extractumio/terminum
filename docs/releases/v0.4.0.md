# v0.4.0 — web access behind tailscale serve

## Changed

- **Web access listens on port 48080 by default**, not 8765. 8765 is iterm-enhancer's port.
  On macOS a listener on every network starts without an error beside a program on
  127.0.0.1 of the same port, so `terminum web on` could open the network next to it without
  a word. Now a port another program holds on 127.0.0.1 counts as in use. A `web.json` that
  names its port keeps it.
- **A listener on 127.0.0.1 says what it is.** `terminum web on` and `terminum status` print
  `127.0.0.1:<port>`, for a proxy on this Mac, instead of network addresses that do not
  answer. The hint is the full command, `tailscale serve --bg --https=443
  http://127.0.0.1:<port>`, and it warns that this replaces what port 443 serves.
- **A new password while web access is on** signs every browser out, and the new password
  signs in at once.
- **Add host and Attach tmux sessions work from a phone or another computer.** Before, the
  form waited on "Looking for running sessions…" and the refusal stayed in the banner.
- **Form fields on a touch screen are at the text size.** iOS no longer zooms in on a small
  field; pinching still zooms.

README has a new section, "Over Tailscale": `https://<mac>.<tailnet>.ts.net`, another service
on its own port, and a name of its own as a Tailscale Service.

## Upgrading

`terminum upgrade`. If web access was on with the old default, it now listens on 48080; to
keep 8765, set `"port": 8765` in `~/.terminum/state/web.json` and run `terminum web off`,
then `on`.

## Validation

The following pass on the released tree:

- Rust unit tests and `cargo clippy` with no warnings; UI, page and script unit tests
  (`make test`).
- The protocol checks against a private terminumd and tmux server: core, access, restore,
  sizing, remote hosts, your own sessions here and on a host (stand-in ssh).
- The page's browser checks in Chromium and WebKit, at a wide and a phone size. The Files
  panel's browser checks, and the live checks against a private tmux server.
- `scripts/security_check.sh`, and the installer's check in a temporary home.
- By hand: sign-in through `tailscale serve` and a Tailscale Service from another device.

Not checked: a real sshd for remote hosts.
