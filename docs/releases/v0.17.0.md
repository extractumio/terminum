# v0.17.0 — Sessions switch without a jump, diagrams in Files

A minor release: it adds features (diagrams in the Files viewer, deleting a selection in an
agent's input, Files open or closed per session) and changes the page's protocol ("sub" carries
the view's grid), so the next minor after v0.16.0.

## Added

- **Mermaid diagrams in the Files viewer**: a rendered Markdown document draws its ```mermaid
  fences as diagrams, in the theme's light or dark; Source shows a fence's text and Diagram goes
  back. A fence Mermaid cannot draw keeps its text with Mermaid's message. Nothing in a diagram
  runs.
- **Delete a selection in a coding agent's input**: select text in Claude Code's (or Codex's)
  input with the mouse or a finger and press Backspace or Delete; exactly the selection goes, as
  in a text field.

## Changed

- **Docked Files is each session's**: closing it in one session leaves it open in the others;
  switching back shows it as that session had it.
- **A session of your own tmux** is sized to the page that shows it as any pane, without a key
  first (it was drawn scaled down until you typed), and gets tmux's own size back when no page in
  sight shows it.

## Fixed

- **Switching sessions no longer jumps**: the page keeps the session shown before until the new
  one's first frame, which already has the view's size, and draws it at once (the text was drawn
  scaled, then at its size).
- **Text in the wrong place**: rows of a pane's history could show where they do not belong (a
  paragraph doubled, lines of a tool's output among others) when the pane printed while they were
  read, most on a host over ssh. The rows are now read where they moved.
- **"⋯ N more lines of the command" came and went** every 0.6 s while a tool ran (Claude Code
  blinks the running tool's dot), and the page jumped with it; it stays.
- **Hosts no longer collect control clients**: one a dropped link left on a host (tmux keeps it
  for days) is ended when terminum connects again; nothing else there is touched.
