# v0.10.0 — Projects named at once, a modal row menu

## Changed

- **The row's menu is modal**: the page is shaded while it is open, and a press outside it
  closes it without doing anything else (Esc too).
- **A new project is named as you make it**: Add to Project… → New project… asks its name
  ("Group 1" suggested). A double click on a project's name renames it too, as ⋯ → Rename… does.
- **Projects in pastel**: their ten colors are muted and lighter, still far apart in hue.
- **No colored line along a rounded box's side**: a project group is only tinted in its color,
  and a bookmark in the bookmarks' list has the list's wavy orange line.

## Fixed

- Renaming a project did nothing when the name was taken with Enter (Enter pressed Cancel).
- The rename dialog had no style of its own (a bare frame); it looks as the page's dialogs now.
