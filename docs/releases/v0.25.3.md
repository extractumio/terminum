# v0.25.3 — Claude Code's tables and Ask's quote on a phone

A patch release: two fixes on a phone and a new README; nothing new to install or upgrade.

## Fixed

- **A Markdown table Claude Code printed on a phone was text, not a table.** At a phone's 44
  columns Claude Code pads each row to its columns' width and wraps it at a bar in its middle and
  into blank lines, the separator over several lines. The page now joins a table's rows until they
  have as many bars as its separator, and shows it as one table.
- **Ask's quote was pasted folded ("[Pasted text #1 +12 lines]") on a phone though it fitted.**
  The pane was measured while the dialog's keyboard made it short, and a quote was typed only
  within half its rows. The pane is now measured as the dialog opens, and the quote is typed
  whole while the agent's box with it stays inside the pane.

## Changed

- The README leads with what terminum is: a self-hosted, tmux-native IDE for coding agents, local
  and remote.

## Verified

At release, on the delivered tree after `/simplify` over every change since v0.25.2 (its fixes
applied: the table rows' lines read once per scan, one rule for a joined line and for a bar, the
agent box's height from the view): `make test`, clippy clean, the Panel's browser check, the Page's
browser checks (Chromium and WebKit, a wide and a phone size), `web/test/e2e_live.mjs` and
`scripts/security_check.sh` pass. Not verified: both fixes on a real iPhone against a live Claude
Code session.
