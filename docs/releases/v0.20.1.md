# v0.20.1 — MIDI out of the box; Esc from the Files tree; ⌘X

A patch release: small changes to existing features since v0.20.0, nothing new to set up.
The package is about 30 MB larger: it now carries the General MIDI SoundFont.

## Changed

- **MIDI plays on a fresh install.** The package carries GeneralUser GS 2.0.3 by S. Christian
  Collins (its license in `soundfonts/` beside it), so a `.mid` plays without setting anything
  up. Your own `~/.terminum/soundfont.sf2`, or `midi.soundfont` in `settings.json`, still takes
  its place.
- **Look at files one after another**: open a file from the Files tree (Enter or a click; the
  tree keeps the keys), press Esc there to hide View, ↓ and Enter for the next.
- **⌘X cuts** the text selected in a coding agent's input box (copied, then deleted).
- **⌘Z and ⌘⇧Z work after a selection made with the pointer**, which left the keys nowhere.
