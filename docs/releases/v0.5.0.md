# v0.5.0 — drawn tables are tables

## Changed

- **A table a program drew with rules is shown as a table.** Claude Code draws its tables
  with `┌─┬─┐`, `│` and `├─┼─┤`. In a view narrower than the pane, such as a phone or Wrap,
  those rules wrapped and broke apart, and the cells could not be read. Now such a table is a
  widget with an HTML table:
  - its head, and one row per part between rules;
  - a cell the program wrapped over several lines is one cell again;
  - cells wrap at the view's width, and a column of numbers is aligned right;
  - **Copy** gives a Markdown table, and **Raw** shows the drawn lines.

  Tables drawn by rich, by tabulate and by mysql (`+----+`) are found the same way. A table is
  shown as a widget even when the program colored it, and the widget drops the colors.
- **Words in widgets are no longer cut letter by letter in Wrap.** This also fixes Markdown
  tables.
- A Markdown document printed just before a drawn table no longer takes the table's lines as
  a paragraph.

README's "Over Tailscale" starts with a choice between the Mac's own name and a name of its
own (a Tailscale Service), and it says how to give the Mac's name back to another service.

## Upgrading

`terminum upgrade`. Nothing to migrate.

## Validation

The following pass on the released tree:

- Rust unit tests and `cargo clippy` with no warnings; UI, page and script unit tests
  (`make test`).
- The protocol checks against a private terminumd and tmux server: core, access, restore,
  sizing, remote hosts, your own sessions here and on a host (stand-in ssh).
- The page's browser checks in Chromium and WebKit, at a wide and a phone size. The Files
  panel's browser checks, and the live checks against a private tmux server.
- `scripts/security_check.sh`, and the installer's check in a temporary home.

Not checked: a real sshd for remote hosts; a table from a live Claude Code session. The
checks use the shape Claude Code draws.

Known limits:
- A table with rules between its rows but no head shows its first row as the head.
- When rich wraps a first cell and draws no rules between rows, the wrapped part becomes a
  row of its own.
- An unchanged table in a diff's context lines is a widget too.
